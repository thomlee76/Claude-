# Фразовые глаголы 100

100 ежедневных уроков по 7 минут по книге «해커스톡 영어회화 10분의 기적 — 아는 단어로 말하기» (go out … keep up with).

В каждом уроке:
- иллюстрация сцены и ключевые слова;
- основной диалог (6 реплик) с записанной озвучкой ключевой фразы и диалога;
- три small talk: быт, поездка, работа (переговоры, тендеры, дистрибьюторы, поставки);
- тест из 5 вопросов, пятый всегда повторяет предыдущий урок; ошибки собираются в «Повторить ошибки».

## Как открыть

**iPhone / Android (работает без интернета):**
1. Откройте в Safari: https://thomlee76.github.io/Claude-/phrasal-verbs/
2. «Поделиться» → «На экран „Домой“».
3. Откройте приложение с экрана «Домой» один раз при подключённом интернете — все 100 уроков, картинки и озвучка сохранятся на телефоне. Дальше всё работает офлайн.

**Компьютер без интернета:** скачайте один файл `offline/phrasal-verbs-100-offline.html` (≈20 МБ, внутри всё: тексты, картинки, озвучка) и откройте его в Chrome, Safari или Edge.

Прогресс хранится в браузере на том устройстве, где вы занимаетесь.

## Структура
- `index.html`, `sw.js`, `manifest.webmanifest` — приложение (PWA); `sw.js` кеширует все файлы для офлайн-режима.
- `img/` — 100 иллюстраций, `audio/` — 100 аудиофайлов (ключевая фраза + диалог урока).
- `offline/` — однофайловая версия.
- `src/` — исходники уроков (`lessons*.js`), шаблон приложения, скрипты сборки и проверки.

Диалоги, small talk и тесты составлены отдельно; из книги взяты только глагол и ключевая фраза дня.
