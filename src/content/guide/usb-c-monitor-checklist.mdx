## 한 줄 정리

USB-C 단자가 있다고 해서 모두 화면을 출력할 수 있는 것은 아닙니다. **DP Alt Mode** 지원 여부를 먼저 확인해야 합니다.

## USB-C는 모양의 이름일 뿐입니다

USB-C는 커넥터의 **형태**를 가리키는 이름이고, 그 안에서 어떤 신호가 오가는지는 기기마다 다릅니다. 같은 모양의 포트가 다음 중 서로 다른 조합을 지원합니다.

- 데이터 전송만 (USB 2.0 / 3.x)
- 데이터 + 충전 (USB PD)
- 데이터 + 충전 + **영상 출력** (DP Alt Mode)
- Thunderbolt 3 / 4 / USB4 (위 기능 전부 + 고대역폭)

영상 출력이 되지 않는 포트에 USB-C to HDMI 케이블을 연결하면 화면에 아무것도 나오지 않습니다. 케이블 불량이 아닙니다.

## 확인 순서

1. **노트북·스마트폰 사양표 확인**
   "DisplayPort Alternate Mode", "DP Alt Mode", "영상 출력 지원", "Thunderbolt" 표기를 찾습니다.
2. **포트 옆 아이콘 확인**
   번개 모양은 Thunderbolt, `D` 또는 `DP` 표기는 DP Alt Mode를 의미합니다. 아이콘이 없다고 미지원인 것은 아니므로 사양표를 우선합니다.
3. **포트가 여러 개면 각각 확인**
   한쪽 USB-C만 영상 출력을 지원하는 노트북이 많습니다.
4. **필요한 해상도 확인**
   4K 60Hz가 필요하면 DP Alt Mode 1.2 이상과 HDMI 2.0 이상 출력이 필요합니다.

## 충전을 동시에 하려면

USB-C to HDMI **케이블**에는 대부분 전원 공급 기능이 없습니다. 화면 출력과 충전을 동시에 하려면 다음 중 하나가 필요합니다.

- PD 패스스루 포트가 있는 **멀티 허브·도킹 스테이션**
- 노트북의 다른 USB-C 포트를 충전에 사용

## 삼성 DeX를 쓰려면

갤럭시 스마트폰·탭에서 DeX 모드를 사용하려면 기기가 DeX를 지원해야 하고, 케이블은 DP Alt Mode 영상 전송을 지원해야 합니다. 두 조건이 모두 충족되면 별도 앱 없이 TV·모니터에 데스크톱 화면이 표시됩니다.
