## 한 줄 정리

**신호 변환이 필요한 케이블은 대부분 단방향입니다.** 같은 커넥터끼리 잇는 케이블은 보통 양방향입니다.

## 왜 방향이 생기나

같은 규격끼리 연결하는 케이블(HDMI ↔ HDMI, LAN ↔ LAN)은 전선이 양 끝을 그대로 잇기 때문에 방향이 없습니다.

반면 서로 다른 규격을 잇는 케이블은 내부에 **변환 회로**가 들어갑니다. 이 회로는 한쪽에서 들어온 신호를 읽어 다른 규격으로 바꿔 내보내도록 설계되어 있습니다. 회로에 입력단과 출력단이 정해져 있으므로 반대로 연결하면 아무 일도 일어나지 않습니다.

## 대표적인 단방향 제품

| 제품 | 동작하는 방향 | 반대 방향 |
| --- | --- | --- |
| DisplayPort → HDMI | PC의 DP 출력 → 모니터 HDMI 입력 | 동작하지 않음 |
| USB-C → HDMI | 노트북 USB-C 출력 → TV HDMI 입력 | 동작하지 않음 |
| HDMI → VGA | 노트북 HDMI 출력 → 프로젝터 VGA 입력 | 동작하지 않음 |

## 양방향으로 동작하는 대표 제품

- HDMI ↔ DVI (두 규격이 전기적으로 동일한 디지털 신호를 사용)
- HDMI ↔ HDMI, DP ↔ DP, LAN ↔ LAN
- USB-C ↔ USB-C 데이터 케이블

## 구매 전 확인하는 방법

1. **내 기기에서 화면이 나가는 쪽(출력)이 어디인지** 먼저 정합니다. PC·노트북·콘솔·셋톱박스가 출력입니다.
2. **화면을 받는 쪽(입력)** 을 정합니다. 모니터·TV·프로젝터가 입력입니다.
3. 제품 설명에서 "출력 → 입력" 표기가 내 구성과 일치하는지 확인합니다.
4. 방향이 반대라면 반대 방향 전용 제품 또는 별도 컨버터가 필요합니다.

## 잘못 구매했을 때 나타나는 증상

- 화면에 "신호 없음" 메시지만 표시됨
- 기기가 외부 디스플레이를 아예 인식하지 못함
- 전원 표시등은 켜지지만 영상이 없음

이런 증상은 케이블 불량이 아니라 **방향 불일치**인 경우가 많습니다. 케이블을 교체하기 전에 방향부터 확인하십시오.
