# 복약 시간

복용 시간 알림 및 복용 기록 웹앱 (PWA). 한국어 인터페이스.

## 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 실제 앱 (단일 파일) |
| `mockup.html` | 승인용 디자인 시안 — 팔레트와 4개 화면 |

## 기본 복용 일정

| 시간 | 약 | 조건 |
|---|---|---|
| 10:00 | 비멕스메타비 + 모바렌 | 식후 |
| 12:00 | ПРЕСТАНС | 식전 |
| 12:30 | 아보다트 + 모바렌 + 미녹시딘 | 식후 (메모: 혈압 주의) |
| 21:00 | 오메가3 + 유산균 이야기 | 식후 |
| 22:30 | 마그네슘 + 수면제 | 취침 전 |

일정은 앱의 **일정** 탭에서 직접 수정·추가·삭제할 수 있다.

## 데이터 저장

- `localStorage` (`boknyak.v1`) — 즉시 저장, 오프라인 동작
- Artifact `db` capability (`app/state`) — 기기 간 동기화. 사용 불가 시 로컬 저장만 유지

## 알림 제한

iOS 웹앱은 앱이 닫힌 상태에서 예약 알림을 띄우지 못한다. 소리 알림은 기본 알람 앱에 유지하고, 이 앱은 복용 체크와 기록을 담당한다. 앱이 열려 있는 동안에는 복용 시간에 배너와 브라우저 알림을 표시한다.
