## Библиотека
`/home/user/Claude-/book/src/figma-lib.js` — **вставляйте её целиком в начало каждого вызова use_figma** (состояние между вызовами не сохраняется). Функции:
- `R(p,x,y,w,h,{fill,stroke,r,sw,dash,op})` — прямоугольник; `E(p,x,y,d,fill,{stroke,sw})` — круг;
- `T(p,text,x,y,{size,w:'r|m|s|b|x',c,width,align,lh,ls})` — текст (если задан width — переносится по ширине, высота растёт вниз);
- `TC(p,text,x,y,w,h,{...})` — текст по центру прямоугольника; `BOX(p,x,y,w,h,text,{fill,stroke,size,w,c})` — карточка с текстом по центру;
- `PILL(p,text,x,y,{fill,c,size})` — плашка-«таблетка», возвращает ширину; `A(p,x1,y1,x2,y2,{c,sw,head,dash})` — стрелка (head:0 — линия без наконечника);
- `ICON(p,name,x,y,size,color,sw)` и `ICB(p,name,x,y,d,bg,color)` — иконки (названия в объекте IC); `NUM(p,n,x,y,{d,fill})` — номер-бейдж;
- `WIN(p,x,y,w,h,title)` — окно-макет приложения (полоса с тремя точками), контент начинается с y+44;
- `FIG(sheet,i,num,title)` — рамка рисунка 1200×760 в ячейке i (0–3) листа 2×2, с подписью «РИС. N.K» и заголовком (заголовок занимает y 64–105, **контент начинайте с y≈140**);
- `NOTE(f,text)` — сноска внизу (y=716). Палитра — объект `P` (bg, card, ink, mut, line, acc/accT терракота, blu/bluT, grn/grnT, amb/ambT, pur/purT, red/redT, dark, soft).

## Порядок работы для каждого файла (4 рисунка)
1. Первый вызов: создайте лист `const sheet=figma.createFrame(); sheet.name='Лист · Раздел N · часть M'; sheet.resize(2520,1640); sheet.fills=F('#D8D2C7');` и нарисуйте **2 рисунка** (`FIG(sheet,0,…)`, `FIG(sheet,1,…)`). Верните id листа и рамок. В конце этого же вызова сделайте `await frame.screenshot({scale:1.5})` для обоих — это и проверка, и экспорт.
2. Второй вызов: `const sheet=await figma.getNodeByIdAsync('<id листа>')`, рисунки в ячейках 2 и 3, скриншоты.
3. **Внимательно посмотрите каждый скриншот**: наложение текстов, текст вылезает за рамки/карточки, обрезанные слова, пустые перекосы, перенос «$184 / 000». Исправьте точечным вызовом (найдите узлы через `frame.children`, поменяйте y/размер/текст) и снова снимите скриншот изменённого рисунка. Для текста с width высоту узнавайте через `node.height` и стройте следующий элемент ниже (`y = prev.y + prev.height + отступ`) — не ставьте элементы по фиксированной сетке, если тексты разной длины.
4. Экспорт: у каждого скриншота в ответе инструмента есть строка `[Image: source: /путь/…png]`. Скопируйте **последний удачный** скриншот каждого рисунка: `cp "<путь>" /home/user/Claude-/book/img/fig-N-K.png` (например fig-2-3.png). Проверьте размер — должен быть 1800×1140.

## Правила содержания
- Содержание рисунков — строго по спецификации `/home/user/Claude-/book/specs/0N.json` (поля title, content). Заголовок рисунка = title (можно чуть сократить, чтобы влез в одну строку ≤ 60 символов). Сноску NOTE используйте для оговорок из content/caption (например «Схематичный макет: интерфейс может отличаться»).
- Если в content есть кнопки/меню интерфейса на английском — пишите их в оригинале (Settings → Connectors), остальной текст — по-русски.
- Каждый рисунок должен быть информативным: макет интерфейса с номерами шагов и пояснениями справа, схема процесса со стрелками, таблица-сравнение, карта карточек и т. п. Минимум пустоты, но без перегруза: шрифт основного текста не меньше 14–15 px, заголовки карточек 18–22 px.
- Шрифт только Inter (Regular, Medium, Semi Bold, Bold, Extra Bold). Цвета 0–1 (функция F/H уже это делает). Никаких эмодзи.
- Не трогайте другие файлы Figma и другие разделы. Не меняйте HTML разделов.
- Код одного вызова — до ~45 000 символов (лимит 50 000); библиотека занимает ~7 700.
