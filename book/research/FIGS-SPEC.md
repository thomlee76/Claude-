# Рисунки для новых глав 5–7 — задание исполнителю

Рисунки книги рисуются кодом в едином стиле (тёплый светлый фон, карточки, оранжевый акцент, шрифт Inter) и сохраняются как `book/img/fig-N-K.png` размером **1800×1140**.

## Инструменты (уже в репозитории)
- `book/src/figma-lib.js` — библиотека отрисовки: палитра `P`, `T` (текст), `R` (прямоугольник), `E` (круг), `ICON`/`ICB` (иконки из `IC`), `NUM` (номер-бейдж), `BOX`, `PILL`, `A` (стрелка), `WIN` (окно-макет интерфейса), `FIG(sheet,i,num,title)` — рамка рисунка 1200×760 с заголовком, `NOTE(f,текст)` — подпись внизу. Прочитайте файл целиком.
- `book/src/render/shim.js` + `book/src/render/run.js` — локальный рендер без Figma: `node book/src/render/run.js <скрипт.js> <имя1> <имя2> …` выполняет figma-lib + ваш скрипт и сохраняет рамки, для которых вызван `frame.screenshot({scale:1.5})`, в `book/img/fig-<имя>.png` по порядку вызовов.
- Образцы скриптов: `book/src/render/s-4-7.js`, `s-6-5.js`, `s-6-7.js`, `s-3-7.js` — прочитайте 2–3 из них. Образцы готовых картинок: `book/img/fig-4-*.png`, `fig-9-*.png` (посмотрите 2–3 через Read).

## Порядок
1. Прочитайте `book/specs/0N.json` (8 описаний: title, caption, content) и места рисунков в `book/sections/0N.html`.
2. Напишите скрипты `book/src/render/s-N-1.js`, `s-N-3.js`, `s-N-5.js`, `s-N-7.js` — по два рисунка на скрипт (лист `figma.createFrame()` 2520×1640, рисунки через `FIG(sheet, i, 'N.K', title)`), в конце `await f.screenshot({scale:1.5}); await g.screenshot({scale:1.5});`.
3. Рендер: `cd /home/user/Claude-/book/src/render && node run.js s-N-1.js N-1 N-2` и т. д.
4. Обязательно посмотрите каждый PNG (Read) и исправьте: текст не вылезает за карточки и рамку, ничего не перекрывается, нет пустых больших областей, всё читается, по-русски без опечаток, названия интерфейса — по-английски как в спецификации. Повторяйте, пока все 8 картинок не будут чистыми.
5. Размер каждого PNG — 1800×1140.

## Правила
- Только содержание из спецификации и главы; никаких выдуманных фактов, цен, кнопок. Данные — условные, с пометкой в `NOTE` («Условный пример»), где уместно.
- Никаких логотипов брендов — только названия текстом.
- Не трогайте другие файлы, кроме своих `s-N-*.js` и `img/fig-N-*.png`. Не коммитьте.
