Глоссарий

Термины, которые встречаются в книге, в алфавитном порядке. Английское название дано так, как оно выглядит в интерфейсе Claude.

Агент (agent)
Режим работы, в котором Claude сам планирует шаги, пользуется инструментами (поиск, файлы, браузер, коннекторы) и проверяет результат, пока задача не выполнена. Раздел 6.
Артефакт (artifact)
Отдельный результат в окне рядом с чатом: документ, веб-страница, набор слайдов, небольшое приложение. Его можно править, скачивать и показывать коллегам.
Задача по расписанию (Scheduled task)
Поручение, которое Claude выполняет сам по графику: каждый день, по будням или раз в неделю. Например, бриф по почте к 8:30. Разделы 2 и 6.
Изолированная среда (sandbox)
Отдельная виртуальная машина, в которой Claude выполняет код и работает с файлами, не затрагивая ваш компьютер.
Коннектор (connector)
Подключение Claude к внешнему сервису: Gmail, Google Calendar, Google Drive, Notion, DeepL, Booking.com и другим. Включается в Customize → Connectors. Раздел 4.
Контекстное окно (context window)
Объём текста, который модель держит в голове в одном диалоге. У актуальных моделей — 1 млн токенов. Рис. 1.8.
Навык (skill)
Папка с инструкциями (файл SKILL.md, шаблоны, справочники), которую Claude подключает сам, когда задача ей соответствует. Раздел 3.
Плагин (plugin)
Готовый набор навыков, коннекторов и команд, который устанавливается одним действием.
Проект (Project)
Рабочее пространство в claude.ai с собственными файлами и инструкциями. Подходит для долгой работы над одной темой, например над проектом SMC.
Промпт (prompt)
Запрос или поручение, которое вы пишете Claude. Хороший промпт описывает цель, контекст, формат результата и ограничения.
Режим разрешений (permission mode)
В Claude Code — насколько самостоятельно Claude действует: спрашивает о каждом шаге, сам правит файлы, только планирует или работает автономно. Рис. 5.3.
Субагент (subagent)
Помощник, которому основной агент поручает часть работы. Несколько субагентов могут работать параллельно. Рис. 6.3.
Токен (token)
Единица текста, которой модель считает объём. В английском тексте это примерно три четверти слова, русский текст расходует токенов больше. По токенам считаются цены API и лимиты.
Уровень усилий (Effort)
Настройка глубины работы модели: Low, Medium, High, Extra high, Max. Чем выше уровень, тем тщательнее ответ и тем быстрее расходуется лимит. Рис. 1.5.
Adaptive thinking
Адаптивное мышление: модель сама решает, сколько размышлять перед ответом. У моделей 5.5 и Fable 5.1 включено всегда.
API
Программный доступ к моделям Claude с оплатой за токены. Нужен, если компания встраивает Claude в собственные системы.
CLAUDE.md
Файл с постоянными инструкциями для Claude Code в папке проекта: правила, структура данных, формат отчётов. Рис. 5.4.
Claude Code
Инструмент Claude для работы с файлами, данными и программами: в терминале, приложении Claude Desktop и в браузере. Раздел 5.
Claude in Chrome
Расширение для браузера Chrome, с которым Claude открывает сайты, заполняет формы и собирает данные от вашего имени. Рис. 6.4.
Cowork
Режим, в котором Claude выполняет длинные многошаговые поручения с файлами и папками, отчитываясь о ходе работы. Раздел 2.
MCP (Model Context Protocol)
Открытый стандарт, по которому Claude подключается к внешним сервисам. На нём построены коннекторы.
Prompt injection
Скрытая инструкция во входящем письме, документе или на сайте, которая пытается заставить Claude сделать то, чего вы не просили. Главный риск при работе с коннекторами и агентами.
Research
Режим исследования: Claude сам проводит десятки поисков, читает источники и готовит отчёт со ссылками.
