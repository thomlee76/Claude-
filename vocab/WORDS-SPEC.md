# Карточки слов: Business English B1 (300 слов)

Список слов и тем зафиксирован в `vocab/topics.json` (12 тем × 25 слов). Порядок и написание слов **не менять**
(британская орфография: licence, organise, apologise, catalogue, enquiry).

Ученик: носитель русского языка, руководитель отдела зарубежных продаж медицинского оборудования
(рентген, УЗИ, цифровые детекторы) — дистрибьюторы в СНГ и Латинской Америке, проект диагностического центра
в Алматы, переписка с партнёрами и головным офисом в Сеуле. Уровень английского — B1.

## Результат
Файл на тему: `vocab/words/<topic id>.json` — JSON-массив из 25 объектов в порядке списка
(UTF-8, `ensure_ascii=False`, отступ 1). Проверка: `python3 vocab/check-words.py vocab/words/<id>.json`.

## Поля
| Поле | Что | Правила |
|---|---|---|
| `id` | `<topic id>-NN` | NN — номер в теме, 01–25 |
| `w` | слово | ровно как в topics.json |
| `pos` | часть речи | одно из: `noun`, `verb`, `adj`, `adv`, `phrase`, `phrasal verb` |
| `ipa` | британская транскрипция | в слэшах, со знаком ударения: `/ˈkʌmpəni/`. Для фраз — целиком: `/ˈbɪznəs trɪp/` |
| `ru` | главный перевод | 1–3 слова, именно в деловом значении |
| `ru2` | другие значения | строка через запятую, можно пустую; если у слова есть важное второе значение (book — книга / бронировать), укажите |
| `ex` | пример | 7–14 слов, B1, естественный деловой английский. Примерно половина примеров — из мира ученика (medical equipment, X-ray, ultrasound, distributor, hospital, Kazakhstan, Almaty, Mexico, Chile, head office in Seoul), остальные — общий бизнес. Без реальных названий компаний |
| `exw` | форма слова в примере | точная подстрока из `ex` (с учётом регистра), которая будет скрыта в упражнении «вставьте слово»: `negotiated`, `follow up`, `Our company` → нет, только само слово: `company` |
| `exRu` | перевод примера | естественный русский, не дословный |
| `col` | 2 сочетания | массив из 2 частых коллокаций: `["place an order", "order confirmation"]` |
| `note` | подсказка | 0–120 символов, по-русски. Пишите, только если полезно: неправильный глагол (`sell – sold – sold`), «ложный друг» (`actual ≠ актуальный`), разница BrE/AmE, частая ошибка русскоговорящих, управление (`apply for a job`). Иначе пустая строка |
| `cefr` | уровень | `A2`, `B1` или `B2` — честная оценка по English Vocabulary Profile |

## Качество
- Значения — деловые. `plant` = завод, `board` = совет директоров, `minutes` = протокол, `lead` = потенциальный клиент (лид), `chair` = вести собрание, `share` = доля/акция, `leave` = отпуск, `terms` = условия.
- Пример должен однозначно указывать на это значение и не подсказывать перевод слишком явно.
- Транскрипции проверяйте внимательно (ударение в глаголах/существительных: `export` n /ˈekspɔːt/ vs v /ɪkˈspɔːt/ — укажите ту часть речи, что в `pos`; во `note` можно упомянуть смену ударения).
- Никаких выдуманных фактов о реальных компаниях и людях.
