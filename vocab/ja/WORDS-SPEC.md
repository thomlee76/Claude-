# Карточки японских слов JLPT N5 с корейским переводом (300 слов)

Список зафиксирован в `vocab/ja/topics.json` (12 тем × 25 слов). Порядок и написание не менять.

Ученик — взрослый носитель **корейского и русского**, руководитель отдела продаж в корейской компании (Сеул),
часто бывает в командировках, любит путешествовать по Японии. Учит японский с нуля до N5.
Все переводы и объяснения — **на корейском** (естественный современный корейский, 해요체/합니다체 не нужен —
пишите кратко, назывными фразами или 다-체 в объяснениях).

## Результат
`vocab/ja/words/<topic id>.json` — массив из 25 объектов в порядке списка (UTF-8, `ensure_ascii=False`, отступ 1).
Проверка: `python3 vocab/ja/check-ja.py vocab/ja/words/<id>.json` — исправлять до OK.

## Поля
| Поле | Что | Правила |
|---|---|---|
| `id` | `<topic id>-NN` | 01–25 |
| `w` | слово | ровно как в topics.json |
| `kana` | чтение | хирагана (катакана для заимствований); для 一つ → `ひとつ`, для いい → `いい` |
| `rom` | ромадзи | Хэпбёрн, долгие гласные через макрон или удвоение: `gakusei`, `benkyō` (с макроном) |
| `pos` | часть речи по-корейски | одно из: `명사`, `대명사`, `수사`, `의문사`, `동사 1그룹`, `동사 2그룹`, `동사 3그룹`, `い형용사`, `な형용사`, `부사`, `조수사` |
| `ko` | главный перевод | 1–3 слова |
| `ko2` | другие значения / вежливая или разговорная пара | строка, можно пустую |
| `hanja` | разбор кандзи по-корейски | для каждого кандзи: `学 배울 학 · 生 날 생`. Если в слове нет кандзи — пустая строка. Используйте корейское чтение ханча (훈음) |
| `ex` | пример | естественное японское предложение уровня N5, вежливая форма です/ます, 8–28 знаков. Только лексика N5. Примерно половина — из жизни ученика: поездки в Японию (東京, 大阪, 京都), работа, коллеги, Сеул/韓国 |
| `exR` | пример с фуриганой | тот же текст, где каждое слово с кандзи записано как `{漢字|かな}`: `{私|わたし}は{学生|がくせい}です。`. После удаления разметки (оставив кандзи) должен получаться ровно `ex` |
| `exw` | форма слова в примере | точная подстрока `ex` (может быть спрягаемая форма: `食べます`, `大きくて`) — её скроют в упражнении «вставьте слово» |
| `exKo` | перевод примера | естественный корейский |
| `col` | 2 частых сочетания | японские фразы: `["ご飯を食べる", "ご飯を作る"]` |
| `exp` | объяснение по-корейски | 40–160 символов: как употребляется, нюанс, вежливость (父 vs お父さん), группа и спряжение глагола (ます-형, て-형 для N5), «ложные друзья» с корейским (勉強 ≠ 면강, 大丈夫), частицы (に乗る, を降りる), омонимы (橋/箸) |
| `lvl` | `N5` | всегда `N5` |

## Качество
- Переводы точные, в основном значении для N5.
- Чтения кандзи — проверять особенно внимательно (今日 きょう, 明日 あした, 大人 おとな, 一つ ひとつ, 二十日 и т. п.).
- Примеры — только простая грамматика N5: です/ます, ました, ません, たい, ～てください, ～があります/います, ～が好きです.
- Никаких реальных компаний и людей.
