# 日本語 復習ノート — PWA

Устанавливаемое приложение (PWA) для повторения японского по урокам Preply LESSON 01–05.
Работает офлайн, ставится на домашний экран iPhone/Android и в док macOS/Windows.

## Что внутри

| Файл | Назначение |
|---|---|
| `docs/index.html` | разметка и стили (홈·라이브러리·플래시카드·퀴즈·분석·노트·설정) |
| `docs/app.js` | логика: маршрутизация, карточки, генератор квизов, прогресс |
| `docs/data.js` | учебные данные: `GRAM`, `VOCAB`, `KANJI`, `QUIZ`, `DLGS`, `SPEAK`, `SHEETS` |
| `docs/sheets/` | листы уроков (WebP) и миниатюры |
| `docs/manifest.json` | манифест PWA: имя, иконки, `standalone`, ярлыки на 퀴즈/단어/한자 |
| `docs/sw.js` | service worker: офлайн-режим и уведомление об обновлении |
| `docs/icon-180/192/512.png` | иконки домашнего экрана (флаг Японии, 日の丸) |
| `docs/favicon-32.png` | иконка вкладки браузера |

Прогресс (выученные слова, кандзи, результаты квизов, заметки) хранится в `localStorage`
браузера — он остаётся на устройстве и переживает обновления приложения.

## Почему `docs/`

GitHub Pages в режиме «deploy from a branch» умеет публиковать только корень репозитория
или папку `/docs`. В этом репозитории Pages уже настроен именно так, поэтому приложение
лежит в `docs/`, а не в произвольной папке.

## Собственный адрес нужен обязательно

Ссылка на артефакт claude.ai открывается внутри страницы claude.ai (iframe), поэтому
«На экран «Домой»» в Safari берёт иконку и имя у claude.ai, а не у приложения — на
домашнем экране появляется логотип Claude. Только когда страница отдаётся со своего
адреса, iOS читает её `<head>`: ярлык получает 日の丸, имя «日本語», полноэкранный режим
и service worker для офлайна.

## Установка на телефон

- **iPhone (Safari):** открыть адрес Pages → «Поделиться» → «На экран «Домой»».
- **Android (Chrome):** открыть адрес → плашка «홈 화면에 추가» → «설치».
- **Desktop (Chrome/Edge):** иконка установки в адресной строке.

Иконка уже добавленного ярлыка операционной системой не обновляется — чтобы сменить её,
ярлык нужно удалить и добавить заново.

## Локальный запуск

```bash
cd docs && python3 -m http.server 8000
```

Открыть `http://127.0.0.1:8000/`. Service worker требует `http(s)://` — открытие
файла через `file://` отключает офлайн-режим, само приложение при этом работает.

## Обновление содержимого

Учебный материал лежит в `docs/data.js`: `GRAM` (грамматика), `VOCAB` (слова), `KANJI` (кандзи),
`QUIZ` (вопросы), `DLGS` (диалоги), `SPEAK` (устные задания), `SHEETS` (листы уроков).
После правки поднять версию кэша `VERSION` в `docs/sw.js`, чтобы устройства получили обновление.
