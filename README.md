# 日本語 復習ノート — PWA

Устанавливаемое приложение (PWA) для повторения японского по урокам Preply LESSON 01–03.
Работает офлайн, ставится на домашний экран iPhone/Android и в док macOS/Windows.

## Что внутри

| Файл | Назначение |
|---|---|
| `app/index.html` | всё приложение: 8 разделов (홈·문법·단어·한자·퀴즈·회화·진도·노트) |
| `app/manifest.json` | манифест PWA: имя, иконки, `standalone`, ярлыки на 퀴즈/단어/한자 |
| `app/sw.js` | service worker: офлайн-режим и уведомление об обновлении |
| `app/icon-180/192/512.png` | иконки для домашнего экрана (флаг Японии, 日の丸) |
| `app/favicon-32.png` | иконка вкладки браузера |
| `.github/workflows/deploy.yml` | автодеплой на GitHub Pages |

Прогресс (выученные слова, кандзи, результаты квизов, заметки) хранится в `localStorage`
браузера — он остаётся на устройстве и переживает обновления приложения.

## Публикация

1. Settings → Pages → Source: **GitHub Actions**.
2. Пуш в `main` или `claude/create-app-765fah` запускает деплой.
3. Адрес: `https://<owner>.github.io/<repo>/`

## Установка на телефон

- **iPhone (Safari):** открыть адрес → «Поделиться» → «На экран «Домой»».
- **Android (Chrome):** открыть адрес → в приложении появится плашка «홈 화면에 추가» → «설치».
- **Desktop (Chrome/Edge):** иконка установки в адресной строке.

После первого открытия приложение работает без интернета. Шрифты Google Fonts
подгружаются онлайн; офлайн используются системные шрифты — содержимое доступно полностью.

## Локальный запуск

```bash
cd app && python3 -m http.server 8000
```

Открыть `http://127.0.0.1:8000/`. Service worker требует `http(s)://` — открытие
файла через `file://` отключает офлайн-режим, само приложение при этом работает.

## Обновление содержимого

Учебный материал лежит в JS-массивах внутри `app/index.html`: `GRAM` (грамматика),
`VOCAB` (слова), `KANJI` (кандзи), `QUIZ` (вопросы), `DLGS` (диалоги), `SPEAK` (устные задания).
После правки поднять версию кэша `VERSION` в `app/sw.js`, чтобы устройства получили обновление.
